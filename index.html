§03 — Case studies

Projects, with the problem behind them

Shipped Python · Pandas · Tkinter

ChurnMerge

The problem: in campaign ops, the same customer often gets called multiple times before a call actually connects — so the same unique ID ends up with several rows of data, each attempt capturing a different piece of the picture. Pulling out the "real" record meant manually writing formulas (VLOOKUPs, nested IFs) per column, per campaign, to decide which attempt's value should win — slow, easy to get wrong, and redone from scratch every time the sheet format changed.

What I built: a local tool where you define the winning logic once per column — highest-ranked value, max numeric, presence-based, specific-over-generic — and it automatically merges every re-churned row into a clean "Final" set, with the original file left untouched. Configs save and reload, so the same logic carries over to the next campaign instead of being rebuilt by hand.
